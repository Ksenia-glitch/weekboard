# Weekboard

Weekly planner for college homework, quizzes, and deadlines.

## Live site

**https://ksenia-glitch.github.io/weekboard/**

## Local

```bash
npm install
npm run dev
```

## Update the live site

After you change the code:

```bash
git add .
git commit -m "Describe your change"
git push
npm run deploy
```
